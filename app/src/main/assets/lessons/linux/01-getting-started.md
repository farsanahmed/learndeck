# Getting Started with Linux

Welcome to your first Linux lesson! Linux is a powerful, open-source operating system used everywhere from servers to smartphones.

## The Terminal

The terminal (or command line) is a text-based interface for controlling your computer. Instead of clicking icons, you type commands.

```bash
# This is a comment
echo "Hello, Linux!"
```

## Basic Commands

Here are the essential commands you'll use every day:

- `ls` — List files in the current directory
- `cd` — Change directory
- `pwd` — Print working directory (show where you are)
- `mkdir` — Create a new directory
- `touch` — Create an empty file

## Try It Yourself

Open a terminal and try these commands:

```bash
pwd
ls
mkdir my_folder
cd my_folder
touch hello.txt
```
