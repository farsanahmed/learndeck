# Python Basics

Python is a beginner-friendly, versatile programming language used for web development, data science, automation, and AI.

## Hello, World!

```python
print("Hello, World!")
```

## Variables and Data Types

Python has several built-in data types:

```python
# Strings (text)
name = "Alice"
greeting = 'Hello, ' + name

# Integers (whole numbers)
age = 25
year = 2024

# Floats (decimal numbers)
price = 19.99
pi = 3.14159

# Booleans (True/False)
is_student = True
has_license = False
```

## Basic Operations

```python
# Arithmetic
total = 10 + 5      # 15
difference = 10 - 5 # 5
product = 10 * 5    # 50
quotient = 10 / 5   # 2.0

# String concatenation
full_name = "Alice" + " " + "Smith"

# String formatting
message = f"Hello, {name}! You are {age} years old."
```

## Practice Exercise

```python
# Create variables for your info
my_name = "Your Name"
my_age = 20
my_height = 5.75

# Print a formatted message
print(f"{my_name} is {my_age} years old and {my_height} feet tall.")
```
